# Chronicles-of-Albion---Saga
Chronicles of Albion è un'applicazione web interattiva per l'apprendimento dell'inglese (A2-B2/C1) attraverso il racconto storico in prima persona. Scopri la storia della Britannia dal 55 a.C., ascolta la narrazione audio, esplora il vocabolario con traduzione hover e mettiti alla prova con un modulo di valutazione da 21 quesiti.
